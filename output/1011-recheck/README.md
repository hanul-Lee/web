# 1011 최종 검토

- `1011_원본과_최종수정안.html`: 26쪽 원본과 남은 수정안을 나란히 확인하는 화면입니다.
- `1011_검증결과와_남은수정안.md`: 페이지별 판단과 붙여 넣을 문구, 웹 변경 내역입니다.
- `1011_남은수정안_인쇄용.pdf`: 검토 HTML에서 원본 이미지를 제외하고 출력한 수정 지침입니다. 제출용 포트폴리오 PDF가 아닙니다.
- `source`: 수정하지 않은 1011 원본 26장입니다. 주요성과는 검토에서 제외했습니다.
- `source-manifest.json`: 원본과 검토용 사본의 SHA-256을 기록합니다.
- `web-validation.json`: 수정한 웹의 로컬 Chrome 확인 결과입니다.

작업 대상은 로컬 웹 소스입니다. 원본 PNG와 기존 다운로드 PDF는 변경하지 않았습니다. 최종 제출 PDF는 수정·익명화·재캡처 후 편집 원본에서 다시 내보내야 합니다.
