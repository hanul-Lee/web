## 웹에 반영한 내용

- 플랫폼의 메인 ‘문제 → 결정’을 같은 문제로 연결했습니다.
- 플랫폼의 넓은 역할 표현을 메뉴·지도 UI와 퍼블리싱 범위로 맞췄습니다.
- ERP의 대표 이미지와 상세에 실제 설계 화면을 추가했습니다. 구조 설명도는 보조 자료로 유지했습니다.
- TBM 실제 모바일 일지·서명 입력·완료 화면을 각각 보여줍니다.
- 공통 UI는 전체 포트폴리오 페이지 이미지 대신 실제 코드·가이드 발췌를 보여줍니다.
- 인트라넷의 실제 예약·근태 신청 화면과 칸반의 실제 작업 생성 화면을 추가했습니다.
- 세로 화면이 작아지지 않도록 이미지 프레임을 조정했습니다.
- 반응형 웹·스카이오토넷·회고의 추상적인 표현을 구체적인 작업 설명으로 정리했습니다.
- 모든 PDF 링크와 변경된 CSS·JS 버전을 갱신했습니다.

## 남아 있는 확인 범위

- 실제 TBM 웹 파일 열람 캡처와 공통 UI의 프로젝트별 적용 캡처는 현재 자료에 없습니다. 화면을 만들어 과거 작업처럼 넣지 않았습니다. PDF·웹은 제공된 자료로 구성했습니다.
- 브라우저 회귀 검사는 Chrome 실행 실패로 완료하지 못했습니다. 이어서 로컬 파일 열기를 요청했으나 브라우저의 URL 보안 정책이 차단했습니다. 수정 후 PC·모바일의 렌더링과 클릭 동작 검증을 완료했다고 주장하지 않습니다.
- 공개 사이트에는 배포하지 않았습니다. 현재 결과는 로컬 수정본입니다.
