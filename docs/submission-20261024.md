## 자료 범위

통합 관리 플랫폼은 전시 공개 이력이 있다는 사용자 설명에 따라 유지했다. 기타 프로젝트의 가상 데이터·리디자인 범위도 사용자 설명을 반영했다. 전시 자료의 공개 범위나 회사의 포트폴리오 사용 승인을 독립적으로 확인한 것은 아니며, 이 작업이 계약 준수나 공개 권한을 보증하지 않는다.

현재 웹에서 읽지 않는 구버전 업무 캡처 23개는 로컬 백업을 만든 뒤 배포 대상에서 제거했다. 과거 Git 이력 재작성은 수행하지 않았으므로 예전 커밋의 파일까지 제거한 것은 아니다. 검토용 원본·백업·고해상도 작업 파일은 Git 제외 output 폴더에 보관한다.
