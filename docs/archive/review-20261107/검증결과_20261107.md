## 기존 검사에서 확인된 실패

`tests/section-spacing.cjs`는 ERP 화면 이미지가 항상 16:9라고 가정한다. 현재 상세 CSS는 해당 이미지에 고정 높이와 `aspect-ratio: auto`를 적용하므로 320px에서 `compact visual frame` 단정이 실패한다.

수정 전 Git HEAD의 HTML·JS·공통 CSS·상세 CSS로 만든 별도 임시 기준본에서도 **동일한 실패**를 재현했다. 이번 변경으로 생긴 실패는 아니다. 이미지 비율을 사용자의 기존 디자인에 맞게 유지했으며 이 검사 파일을 통과시키기 위해 레이아웃을 바꾸지 않았다. 따라서 “기존 테스트 전체 통과”로 보고하지 않는다. 별도의 220회 화면 검사에서는 이미지 왜곡·넘침·텍스트 겹침이 발견되지 않았다.
