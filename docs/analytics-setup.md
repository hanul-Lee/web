# 비공개 방문 통계 (무료 GA4)

현재 상태: 사이트 11개 페이지에 공통 분석 코드를 연결하고 소유자가 제공한 측정 ID
`G-WD9CM53DY0`를 적용했습니다. 공개 사이트 배포와 GA4 실시간 수신 확인은 아직 남아 있습니다.

## 계정 연결

1. https://analytics.google.com/ 에 본인 Google 계정으로 로그인합니다.
2. 계정·속성을 만듭니다. 보고 시간대는 대한민국, 목표는 트래픽 파악과 참여·유지율입니다.
   선택적 계정 데이터 공유는 해제합니다. 서비스 약관은 소유자가 확인하고 동의합니다.
3. 웹 데이터 스트림에 실제 공개 사이트 주소를 등록하고 향상된 측정을 켭니다.
4. 발급된 `G-`로 시작하는 측정 ID를 `analytics.js`의 `measurementId`에 입력합니다.
5. 변경 파일을 사이트에 배포하고 공개 사이트에 접속한 뒤 GA4 실시간 보고서를 확인합니다.

분석 서비스 자체는 Google의 무료 표준 버전입니다. Analytics 360, 광고 및 유료 클라우드
서비스 연결은 필요하지 않습니다. 측정 ID는 공개 식별자이며 비밀번호나 API 비밀키가 아닙니다.

## 통계 확인

- 유입 경로: 보고서 → 획득 → 트래픽 획득 (소스/매체)
- 인기 프로젝트·조회수·평균 참여시간: 보고서 → 참여 → 페이지 및 화면
- 신규·재방문: 유지율 보고서 (메뉴 명칭은 계정 설정에 따라 다를 수 있음)
- PDF 다운로드: 향상된 측정의 `file_download` 이벤트
- 이메일·전화 클릭: `contact_click` 이벤트의 `contact_method` (`email` / `phone`)

참여시간은 화면에 실제로 머문 시간을 중심으로 측정합니다. 재방문은 브라우저 식별 기준이라
쿠키 삭제·다른 기기·추적 차단에 영향을 받습니다. 설치 이전 방문 기록은 복원하지 않습니다.
localhost와 파일로 연 페이지, Do Not Track을 켠 브라우저는 이 코드에서 수집하지 않습니다.

GA4 관리 → 계정/속성 액세스 관리에서 본인 외 사용자가 없는지 확인합니다.
보고서를 공개 공유하거나 공개 대시보드에 내보내지 않습니다. 사이트에 별도 관리자 HTML은
필요하지 않습니다. 통계와 인증은 Google이 관리합니다.

개별 채용 공고·이력서 등 링크별 유입을 구분하려면 예를 들어
`?utm_source=saramin&utm_medium=resume&utm_campaign=portfolio`를 사용합니다.
이름·이메일·전화번호 등 개인 정보는 캠페인 값에 넣지 않습니다.
