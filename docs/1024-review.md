# 1024 수정본 검토 및 이미지 사용 안내

## 웹 반영
- TBM: 오늘안전 재구성 화면, 가상 현장·사용자, 검정 로그아웃, 서명 완료 상태. 작은 모바일 파일은 글자와 선을 다시 렌더링했습니다.
- 홈 확인 상태: 완료 3개와 대기 1개에 맞춰 3 / 4로 정리했습니다.
- 공통 UI: 테라코타 색상 유지. 실제 코드와 기존 가이드 캡처를 새 팔레트·입력·검색 예시로 교체했습니다.
- 인트라넷·PSC: 1024 폴더의 수정된 원본 이미지 사용. 단순 확대를 고해상도 복원으로 표시하지 않았습니다.
- ERP: 가상 서비스 예산노트, 새 데이터·화면 구성. PDF 변경에 따른 웹 시안 미사용 사실과 설명용 재구성을 명시했습니다.
- .impact-flow strong의 기존 스타일은 SCSS/CSS 모두 보존했습니다.

## ERP 이미지 크기
같은 UI 원본을 직접 렌더링했습니다. AI 이미지의 글자나 숫자를 보간한 결과가 아닙니다.
- web/erp-dashboard.png: 1600 × 900
- pdf/erp-dashboard-3200.png: 3200 × 1800
- pdf/erp-dashboard-4800.png: 4800 × 2700
- 상세 화면도 같은 세 크기입니다. 표지 목업은 1600 × 1000 / 3200 × 2000 / 4800 × 3000입니다.
- 세로 메뉴 요소·상태 요소·설명도는 각각 비율을 유지한 1×/2×/3× 크기로 제공합니다.
- web-assets: 실제 웹에서 사용한 손실 없는 WebP 파일.
- replacement-pages: PDF 12, 16, 17, 18, 19, 22쪽의 교체 예시. 1920 × 1080 및 3840 × 2160 PNG.
- 표지 목업 자체는 제목·포트폴리오 설명문을 포함하지 않습니다. 목업 안의 UI 텍스트는 포함합니다.

## 검토 중 확인한 사항
- 1024/12.png: 실제 수기 일지에 회사명과 작성 내용이 남아 있습니다. 이름만 흐린 것만으로 실제 업무 문서가 없어지는 것은 아니므로, 실제 필기를 쓰지 않는 새 항목 설명도로 대체했습니다.
- 1024/22.png: 실제 SCSS 발췌가 남아 있습니다. 재작성한 UI 상태 예시로 대체했습니다.
- 지도 플랫폼 등 회사 업무 자료의 공개 권한은 이미지 검토만으로 확인할 수 없습니다. 모든 자료의 보안서약서 준수 여부를 보장하는 검토는 아닙니다.
- 재구성 화면을 실제 납품 화면이나 성과 증빙으로 소개하지 않도록 캡션을 구분했습니다.

## 검증
- ERP 원본의 일반 텍스트 / 배경 색 조합 최저 명도 대비: 5.48:1. 4.5:1 이상.
- 근거: https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum
- 회사명·실명·프로젝트 코드·실제 비용 대신 가상 명칭 및 수치를 사용했습니다.
- 비용 60,000,000 + 36,000,000 + 24,000,000 = 120,000,000원.
- 시간 120 + 72 + 48 = 240h. 총 예산 200,000,000원 대비 60%.
- PC 1440px / 모바일 390px에서 메인 및 변경한 5개 상세 페이지: 이미지 누락·가로 넘침·스크립트 오류 없음.
- 이미지 확대/닫기, 모바일 메뉴 확인.
- 10개 프로젝트 템플릿과 33개 이미지 참조 검증. 기존 테스트의 PDF 캐시 버전 기대값은 현재 사이트 값(20261022-linked)으로 임시 치환하여 검사했습니다. 테스트 파일 자체는 수정하지 않았습니다.

## 반영 범위
로컬 웹 파일에 반영했으며 공개 서버로 배포하거나 Git 커밋/푸시하지 않았습니다.
1024의 원본 PNG와 현재 다운로드용 assets/portfolio.pdf는 덮어쓰지 않았습니다. 위 교체 이미지를 반영해 PDF를 다시 내보내기 전까지 웹의 다운로드 링크는 기존 PDF입니다.


## 15:43 폴더 업데이트 반영
사용자가 다시 내보낸 모바일 홈·일지·마이페이지·서명 완료와 ERP 전체·상세·구조·메뉴·초과시간 이미지를 웹에 우선 적용했습니다. 모바일 313px/338px 원본은 원본 디자인 보존을 위해 손실 없는 WebP로 변환했으며, 단순 확대를 화질 복원으로 주장하지 않습니다. ERP 고해상도 1×/2×/3× 출력물은 동일한 원본 설계에서 제작한 파일을 별도로 제공합니다. 대비 검증 수치는 직접 제작한 ERP 원본에 대한 결과이며 새로 제공된 모든 비트맵에 대한 인증은 아닙니다. 다운로드용 기존 PDF는 변경하지 않았습니다.
