## PDF 형식·가독성

1. 원본 편집 파일에서 텍스트 레이어를 유지해 PDF로 내보내기. 페이지 전체를 이미지로 저장하는 방식은 피하기. 원본 편집 파일이 없다면 OCR은 임시 대안이며 한글 오인식 확인이 필요.
2. 작은 회색 본문은 크기와 대비를 높이고, 한 화면에 맞춘 배율에서 읽히는지 확인. 1920×1080 원고 기준 본문 24–28px 정도를 출발점으로 조정하고 캡션도 충분히 크게 배치.
3. 화면 캡처의 핵심 영역을 확대하고 불필요한 여백·긴 설명을 줄이기. 이미지 압축 시 UI 글자가 흐려지지 않는지 확인.
4. 새 PDF에서 ‘현장 설명’, ‘서명’, ‘퍼블리싱’을 검색하고, 문장을 선택·복사해 한글이 정상인지 확인. 폰트 포함 여부도 확인.
5. 페이지 통합 후 목차·책갈피·집/메뉴 아이콘의 이동 대상과 이메일·웹 링크를 새 페이지에 맞춰 재설정.
6. 수치 없는 한계 설명은 사례 결과에서 한 번만. 문제–결정–결과–회고 제목을 모든 사례에 반복하기보다 플랫폼은 대안 비교, TBM은 기능 확장, ERP는 정보 위계를 중심으로 구성.
